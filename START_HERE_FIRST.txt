PP TRADING JOURNEY — V5 GLASS EDITION
=====================================
This ZIP upgrades your EXISTING GitHub Pages site. Do not upload the ZIP itself.

WHAT CHANGED
1. ACCOUNT SWITCHER INSIDE the Performance chart card on Overview AND Insights,
   right next to the 7D / 14D / 30D / All Time buttons.
2. Choosing an account updates the chart, key dashboard stats, funded progress,
   calendar and recent trades using ONLY that account.
3. Best day / Toughest day / Active days mini-insights for the selected chart period.
4. Softer pearl-white glass, brighter accents, tactile hover/press feedback,
   polished dark theme, mobile layouts and chart hover/touch marker.
5. Dynamic motivational daily pulse based on your selected account's performance.
6. SAFETY: if loading existing cloud data fails, the app now stops rather than
   silently constructing an empty editable workspace that might overwrite records.
7. Existing Add Trade, funded accounts, certificates, settings, password recovery,
   journal and JSON backup remain.

UPLOAD TO THE SAME GITHUB REPOSITORY
1. Export JSON backup of your trades first (Settings > Export all data).
2. Extract this archive. Upload the CONTENTS of this folder to your EXISTING
   GitHub repository ROOT. Recommended: GitHub Desktop > Clone > Copy extracted
   files and folders > Replace > Commit > Push origin.
3. IMPORTANT: Root index.html MUST be replaced. It loads js-v5/app.js and
   styles-v5.css. New files in the wrong folder won't update the website.
4. If Supabase was configured: copy only the PUBLIC project URL and
   publishable/anon key from old js-v4/config.js into new js-v5/config.js.
   NEVER commit Supabase secret or service-role keys.
5. Wait for GitHub Actions > Pages deployment to finish successfully.
6. Visit your SAME Pages URL in a PRIVATE/INCOGNITO browser window.
7. Confirm the small footer label says: V5 • GLASS EDITION.
